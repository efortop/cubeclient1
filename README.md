# Pixel 10 — тёмный концепт-лендинг

Минималистичный одностраничный сайт про Google Pixel 10: чёрная палитра,
крупная типографика, плавные анимации и аккуратные «фишки» устройства.

> Неофициальный концепт. Не связан с Google LLC. Изображения сгенерированы.

## Что внутри

- **Hero** — построчное появление заголовка, парящий рендер телефона с параллаксом.
- **Плавные анимации** — reveal-блоки по скроллу, магнитные кнопки, подсветка,
  следующая за курсором, точечный спотлайт на карточках, счётчики характеристик.
- **Переключатель цвета** — Обсидиан / Индиго / Фарфор меняет подсветку сцены.
- **Секции** — дизайн, фишки Tensor G5, камера, галерея «Снято на Pixel 10»,
  характеристики, финальный призыв.
- **Доступность** — поддержка `prefers-reduced-motion`, фокус-обводки, семантика.

## Стек

Чистые HTML, CSS и JavaScript. Без сборки и зависимостей.
Шрифты — Unbounded и Manrope (Google Fonts).

## Запуск

```bash
python3 -m http.server 3000
```

Откройте <http://localhost:3000>.

## Структура

```
index.html      разметка и контент
styles.css      тёмная тема, сетки, анимации
main.js         интерактив и observers
assets/         изображения (рендеры и фото)
```
