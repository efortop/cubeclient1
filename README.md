# Портфолио веб-разработчика

Современный анимированный сайт-портфолио начинающего веб-разработчика:
тёмная тема, крупная типографика, живые анимации и адаптив от 320px.

## Что внутри

- **Прелоадер** со счётчиком загрузки и плавным уходом.
- **Hero** — построчное появление заголовка, «печатающийся» код на JavaScript,
  3D-наклон карточки, парящие бейджи, плавающие фоновые градиенты.
- **Бегущая строка** навыков с паузой при наведении.
- **Обо мне** — статус «ищу первых клиентов» и карточка с фактами.
- **Навыки** — три карточки (HTML / CSS, JavaScript, разработка сайтов)
  с полосами прогресса и подсветкой, следующей за курсором.
- **Работы** — три концепт-проекта с зумом превью и модальным окном кейса.
- **Процесс** — четыре шага работы с клиентом и сроками.
- **Контакты** — email, кнопка копирования, форма, которая собирает письмо.
- **Анимации** — reveal по скроллу, счётчики, кастомный курсор, магнитные
  кнопки, прогресс-бар скролла, зерно на фоне.
- **Доступность** — поддержка `prefers-reduced-motion`, фокус-обводки,
  семантика, `aria`-атрибуты.

## Стек

Чистые HTML, CSS и JavaScript. Без сборки и зависимостей.
Шрифты Unbounded и Manrope лежат локально (`assets/fonts`), поэтому сайт
работает даже без доступа к Google Fonts.

## Где посмотреть

**GitHub Pages:** <https://efortop.github.io/cubeclient1/>

Сайт раздаётся из ветки `gh-pages`. Любой пуш в `main` автоматически
пересобирает опубликованную версию (workflow «Deploy to GitHub Pages»).

## Запуск локально

```bash
python3 -m http.server 3000
```

Откройте <http://localhost:3000>.

## Структура

```
index.html      разметка и контент
styles.css      тёмная тема, сетки, анимации
main.js         прелоадер, reveal, курсор, тилт, модалка, форма
assets/         шрифты и превью проектов
.nojekyll       отключает Jekyll на GitHub Pages
```
